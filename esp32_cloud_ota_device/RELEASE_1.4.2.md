## 安装与回退

已运行 1.4.1 且离线唤醒正常的设备，在设备网页执行 OTA 检查并安装 1.4.2。旧分区设备不能直接安装；需要先按 README 完成 USB 分区与模型迁移，本次未执行该操作。

升级后先使用增益 5、灵敏度 50、降噪开启；分别验证静音不应答、五轮以上连续对话、网页/按键结束、重启保留设置，再比较带壳/裸板录音。降噪不等于回声消除，不能仅凭照片判断外壳影响。

服务器回退可将 `current` 链接恢复到上述上一代码并重启服务；停止继续分发可撤回 1.4.2。不要把旧 1.2.1 指针恢复操作当成设备回滚：已安装设备不会自动降级。本轮无数据库模式迁移、无 Git 提交/推送、无 USB 擦写。
