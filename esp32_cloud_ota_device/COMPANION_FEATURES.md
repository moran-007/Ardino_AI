# 单麦克风陪伴功能（2026-10-02）

本次新增个人记忆、云端备份、实验自定义唤醒、番茄钟、每日简报和回应互动。只接入 `esp32_cloud_ota_device`，多麦克风工程未同步。使用现有云端 AI、语音、设备认证和 ESP SR 16M 分区。

## 个人记忆

登录设备后台 → **个人记忆**。支持查看、添加、修改、按编号忘记、全部清空、关闭自动记录、关闭对话使用、关闭云端备份，以及显式从云端恢复。

| 类别 | 可记录示例 | 用途 |
| --- | --- | --- |
| 称呼 | 我叫小明、请叫我小默 | 合适时称呼使用者 |
| 兴趣 | 我喜欢机器人、我不喜欢足球 | 选择相关例子和话题 |
| 交流偏好 | 我希望你回答简短一些 | 调整回答方式 |
| 学习目标 | 我正在学习英语、我的目标是学会编程 | 提供符合目标的建议 |
| 日常习惯 | 我每天读书、我习惯晚上学习 | 理解主动告知的习惯 |

自动记录仅匹配明确的自我描述开头，标记为 `observed`；“记住…”、网页添加或修改标记为 `explicit`。当前问题优先于旧偏好，观察记录不作为已验证事实。相同记录不会反复写盘；主动确认会把观察记录提升为明确保存。最多 24 条，每条最多 180 个 UTF-8 字节。暂按设备的一位使用者管理，不识别说话人，也不推断年龄、身份或人格。

语音例子：

```text
记住我喜欢机器人
记住我希望你回答简短一些
你记住了什么
忘记我的名字
忘记个人记忆1号
清空个人记忆
关闭个人记忆
停止收集个人信息
```

拒绝已识别的常见密码、证件、联系方式、财务和健康词语，以及长串数字。这是有限规则筛查，请勿输入敏感信息。

当前主记录位于设备文件系统 `/personal_profile.json`，通过临时文件、读回校验和重命名更新，设备保存成功后才能确认。损坏主文件不会悄悄加载旧副本。清理旧副本失败会明确提示，再次保存或清空可重试；普通文件删除不等于介质取证级擦除。

云端保存设备独立的 SQLite 备份，使用递增版本和内容指纹防止旧数据覆盖新数据。网络失败保留本机记录，空闲时每 60 秒重试；从云端恢复需在网页明确操作，不会自动替换本机。清空后联网同步空快照；关闭云端备份后云端清除特征条目，保留版本和策略以防旧快照恢复。

**关闭云端备份只停止持久保存。** 使用云端回答且开启个人记忆时，特征仍作为本轮上下文发送到现有 AI 服务。关闭“对话使用个人记忆”才能停止这份特征上下文。此功能让回答更了解使用者，不会训练、升级或修改模型权重。

特征删除后不再通过旧对话记忆重建。已有问题、回答和最新诊断录音仍按原系统策略保留；“清空个人记忆”不是删除全部历史。以后接 SD 卡时，个人记忆和唤醒模块的 `begin(fs::FS&)` 可接收 SD 文件系统；本次尚未增加 SD 硬件驱动或迁移流程。

## 实验自定义唤醒

登录后台 → **语音与音量** → 自定义唤醒。先保存新名称，在安静环境点击“录制 1 份样本”，看到录音状态后清晰说一次，约 3 秒后完成。建议录制 3 份，每次说法一致、在 0.3–2 秒内说完并停顿；至少 1 份有效样本才能手动启用。网页或实体中断键可取消录入，清空会停用；改名会清除旧样本并要求重新录制。

这是本机声音模板匹配：能量分段、归一化频带特征和 DTW；偏向录入者的发音。它不修改官方 WakeNet 模型，也不把填写的文字直接转换成可靠识别模型。启用后使用自定义监听，关闭后回到原官方唤醒设置。原模型包和安全暂停流程继续保留。

模板存储于 `/custom_wake.bin`；不保存录入的原始 PCM，不上传唤醒模板，不持续上传监听声音。文件损坏会停用并要求清空后重录；旧副本删除失败会报告并提供重试。模板仍是声音特征，应作为个人数据管理。误唤醒、漏唤醒、环境噪声、不同距离和多人发音的表现需实机测量；合成信号检查不能当作准确率。

## 番茄钟与专注

后台新增 **番茄钟**，支持开始、暂停、继续、停止、跳过阶段和调整时长。默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟；完成 4 次专注后进入长休息。

可说“开始专注”“开始专注十五分钟”“暂停专注”“继续专注”“停止专注”“跳过当前阶段”“查询专注”。

计时在设备离线运行，屏幕显示阶段和剩余时间，暂停待机轮播；阶段转换时空闲播放短提示音。正在对话或闹钟响起时等待空闲再提示，不抢占麦克风。跳过专注不计为完成；重启从最近一分钟内的检查点恢复为暂停，需手动继续，不推算断电期间完成次数。后台延迟轮询只进入一个完整的下一阶段，不虚构错过的完整轮次。设置与状态使用 NVS 的单个 JSON 值保存，写入失败有错误提示和重试。

## 每日简报与回应

说“早上好”“每日简报”或“今天有什么安排”，根据北京时间、设备当前天气、便签和待办生成简报。没有有效天气或列表会明确说明，不编造日程。

回应时屏幕根据问候、鼓励、庆祝、难过或晚安等词选择已有表情；预览、闹钟、配网等原有优先级继续生效。

**回应时的小动作** 位于语音页，默认关闭。先用原舵机命令确认机构安全范围，再配置一个通道，跨度不超过 30°。问候、鼓励和庆祝时以每 40 ms、1° 小幅移动并返回原指令角度；PWM 关闭或当前指令角度在范围外时跳过，手动改角度会接管。录音、样本录入和专注阶段停止动作。没有位置反馈，界面角度是指令值，仍需实物校准。

## 云端兼容与安装

先更新云端服务，再安装包含这些功能的设备固件。SQLite 表在现有启动迁移中创建；不需要新增 AI 密钥或修改现有供应商配置。

新增认证接口 `GET/PUT /voice-api/v1/personal-profile`；本地指令结果新增可选 `personal_profile` 快照，响应包含 `profile_revision`。旧固件省略快照仍兼容。新固件连接旧云端会提示同步失败，云端特征功能需新版服务。

验证和实机待验项见 [COMPANION_VERIFICATION.md](tests/COMPANION_VERIFICATION.md)。本次不刷写设备、不部署云端、不发布 OTA；版本号保持当前源码值，构建产物不是已发布版本。
