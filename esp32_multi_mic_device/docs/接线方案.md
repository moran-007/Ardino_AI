# 多麦克风接线方案：兼容单麦克风，保持当前端口

日期：2026-10-02；对应同目录上级的 esp32_multi_mic_device 工程。主控按 ESP32-S3、16 MB Flash、OPI PSRAM。按 GPIO 编号接线，连接器编号是本次新定义，不代表现有模块的物理针序。

## 设计边界

保留原屏幕、四路舵机、功放、按钮、ADC 和第一只 INMP441 接线。新固件默认只启用 MIC1，J_MIC2/J_MIC3 可先不安装。安装后通过 /mic count 1、2、3 设置数量，任意组合用 /mic mask；配置重启后保持。

标准 I2S 每条数据线只有左右两个时隙，三只 INMP441 不能同接 GPIO21。MIC1 选左声道，MIC2 选右声道，共用 GPIO21；MIC3 使用第二个 I2S 控制器和独立 GPIO11/18/38。第二组时钟独立，不与 GPIO42/41 短接。依据：[INMP441 数据手册](https://invensense.tdk.com/wp-content/uploads/2015/02/INMP441.pdf)、[ESP32-S3 I2S 文档](https://docs.espressif.com/projects/esp-idf/en/latest/esp32s3/api-reference/peripherals/i2s.html)。

新固件支持读取三路、单独诊断、固定通道或自动选路，录音及离线唤醒仍使用单声道。两组独立时钟的采样不保证同步，本版本没有声源定位或波束形成；阵列算法需要另行设计同步与校准。

## 麦克风连接器：逐针连接

三个接口统一为六针防反插连接器。从主板连接器插接面看，由丝印三角和方形焊盘标出 1 脚；模块端按信号名重新排线，不按商家板的针序直接插。

| 主板接口针号 | 模块信号 | J_MIC1 | J_MIC2（可选） | J_MIC3（可选） |
| ---: | --- | --- | --- | --- |
| 1 | VDD | 3V3_MIC | 3V3_MIC | 3V3_MIC |
| 2 | GND | GND | GND | GND |
| 3 | SCK/BCLK | GPIO42 | GPIO42 | GPIO18 |
| 4 | WS | GPIO41 | GPIO41 | GPIO38 |
| 5 | SD | GPIO21 | GPIO21 | GPIO11 |
| 6 | L/R | GND（左） | 3V3_MIC（右） | GND（左） |

L/R 必须固定电平，不能悬空。每只 VDD/GND 就近放 100nF 去耦；每个接口可预留 4.7µF。SD_A(GPIO21) 与 SD_B(GPIO11) 各预留 100kΩ 到 GND，按 INMP441 数据手册的总线高阻要求设置，结合已有模块电阻决定装配。电源用 3.3V，禁止 5V。

## 电源与线束走向

5V 输入经保护、开关后在入口分支：5V_LOGIC→ESP32 VIN；5V_AUDIO→功放；5V_MOTOR→步进驱动。舵机另按四路同时动作峰值选择供电，独立电源只共地，正极不能直接并联。3V3_MIC 从主控 3.3V 稳压输出分支供三只麦克风，先确认稳压器余量；屏幕也使用 3.3V。电池充电、升压和 GPIO1 分压沿用单麦克风版本说明，GPIO1 禁止直接接电池。

麦克风接头放在靠近拾音开孔的一侧；功放、喇叭线、升压和电机驱动放另一侧。不要遮住底部声孔。三只麦克风的机械位置和间距先留可调整空间，未定算法前不声明最佳阵列间距。

BCLK/WS 以短主干加短分支连接 MIC1/MIC2/功放，不要先绕到功放再长距离回麦克风。MIC3 单独成束。面包板验证先尽量控制在约 10cm 内，长线须用示波器检查边沿和串扰。排线可按 GND/BCLK/GND/WS/GND/SD 排列，电源与 L/R 另走；六针接口不等于只允许六根线束线。

PCB 用连续地平面；信号下方不要跨地缝。功放、电机、舵机大电流回路回到电源入口，不经过麦克风细地线。预留 BCLK/WS 源端 22～47Ω 串阻焊位，具体装值通过波形验证，不能在共享 SD 上用串阻替代左右声道选择。模拟拾音区域避开天线、电机相线和扬声器机械振动，天线区按模组手册保持净空。

## 固件启用范围与验证

新工程 voice_input.cpp 使用 I2S_NUM_0 的左右槽接 MIC1/2，并在启用 MIC3 时初始化 I2S_NUM_1 RX（BCLK18/WS38/DIN11）。三路 GPIO 已加入集中引脚表与冲突检查，读取、取消录音和硬件释放都处理第二控制器。安装数量与固定/auto 选择由 multi_mic_config 保存；未安装通道不参与选路。原单麦克风运行工程保持不变。

1. 只接 MIC1，确认现有录音、播放、屏幕和舵机正常。
2. 断电安装 MIC2，核对 L/R 为 3.3V；/mic count 2，分别 /mic select 1 和 /mic select 2，使用 /mic test 及录音验证左右路。
3. 安装 MIC3 后 /mic count 3，再 /mic select 3 验证第二控制器，最后 /mic select auto 验证三路选路。
4. 测量三路供电、检查削波、底噪、串扰和丢帧；同时播放及舵机动作时复测。
5. 若需要定位/波束形成，先验证跨控制器同步和长期漂移，再确定最终电路。

上述 GPIO 分配已对新工程 hardware_pins.h 核对，没有占用屏幕、四舵机、按钮和功放端口。软件验证记录见 ../tests/验证记录.md；尚未进行实物接线或 PCB 电气验收。
