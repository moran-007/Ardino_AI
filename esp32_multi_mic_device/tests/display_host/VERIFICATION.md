## 自动检查

- `run.ps1`：调用生产显示/表情/缩略图代码、真实 Adafruit GFX 与 U8g2 字库。192 次页面和状态绘制覆盖两种屏幕、四个方向；逐帧检查 48 组表情在 9 个场景、5 个时间点和两种造型下不超出区域。
- 校验网页亮度范围、GPIO1 互斥、ADC 平滑和端点、PWM 失败回退、NVS 写入失败与冷启动恢复、独立语音布局的四种组合、照片缓存和退出状态条后的恢复。
- 校验表情 ID 严格解析、重复/非法/空选择、48 位高位保存、单组固定、多组不连续重复、设备忙时拒绝预览、8 秒和手动结束预览恢复。
- 预览恢复检查曾失败：8 秒预览期间轮播继续计时，结束跳页；暂停轮播时钟后，同一检查通过。
- 实际生产 HTTP 输出生成 96 张 96×96 BMP。分别验证 48 张发光表情和 48 张全身角色像素不同；初次发现两对横屏重复画面，调整后通过。
- 16 张原生尺寸二维码截图由 zxing-cpp 独立解码。编码入口使用 Python qrcode 测试替身，验证内容、白边、缩放、排版和缓存重试；不代替 ESP32 编码器/手机相机的实测。
- Arduino CLI：ESP32-S3 / ESP SR 16M / OPI PSRAM，使用项目现有 Arduino-ESP32 3.3.11 与绘制库构建。
